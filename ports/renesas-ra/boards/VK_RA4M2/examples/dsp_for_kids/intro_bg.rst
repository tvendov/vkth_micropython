Първи стъпки с MicroPython на Renesas RA
=========================================

Този урок ще ви преведе през настройката на MicroPython,
получаването на команден ред, използването на хардуерните периферии,
работата с вътрешната флаш файлова система, режимите на рестартиране
и зареждане, и фабричното нулиране на вътрешната файлова система.

Изисквания
----------

Нужна ви е платка. За информация относно наличните платки,
моля вижте общата информация за Renesas RA порта: :ref:`renesas-ra_general`.

Нужен ви е USB-Serial кабел за свързване на платката с компютъра.
Моля вземете тип с отделни сигнални пинове, за да можете да свържете
към UART TX и RX пиновете на платката.

Програмиране на MicroPython образа с J-Link OB
------------------------------------------------

Платката има вграден програматорен интерфейс наречен J-Link OB.
Чрез софтуера J-Link можете да програмирате двоичния образ "firmware.hex"
на MicroPython върху платката през J-Link OB.

Можете да изтеглите J-Link Software and Documentation pack от https://www.segger.com/downloads/jlink/.

След инсталиране на J-Link Software, стартирайте програмата J-Flash-Lite. След това посочете следното устройство в менюто Device select на J-Flash-Lite.

===============  ================
    Платка            Устройство
---------------  ----------------
 EK-RA4M1           R7FA4M1AB
 EK-RA4W1         R7FA4W1AD2CNG
 EK-RA6M1           R7FA6M1AD
 EK-RA6M2           R7FA6M2AF
 RA4M1 CLICKER      R7FA4M1AB
===============  ================

Изберете hex файла на фърмуера в Data File на J-Link-Lite и натиснете бутона Program Device, за да програмирате фърмуера.

Получаване на MicroPython команден ред
---------------------------------------

Свържете кръстосано RX/TX/GND пиновете на USB-Serial кабела към TX/RX/GND пиновете на платката.

===============  ===============  ===============
     Платка       USB Serial RX    USB Serial TX
---------------  ---------------  ---------------
 EK-RA4M1             P411             P410
 EK-RA4W1             P205             P206
 EK-RA6M1             P411             P410
 EK-RA6M2             P411             P410
 RA4M1 CLICKER        P401             P402
===============  ===============  ===============

Достъпете MicroPython REPL (Python командния ред) през USB серийна или UART връзка с 115200 бод, 1 стоп бит и без бит за четност, като използвате любимия си терминален софтуер — picocom на Linux или Tera Term на Windows. Можете да опитате на Linux::

      $ picocom /dev/ttyACM0

Трябва да видите MicroPython REPL командния ред по следния начин::

   MicroPython v1.20.0 on 2023-04-27; EK-RA6M2 with RA6M2
   Type "help()" for more information.
   >>>
