[ CONTENTS ]

  This software package contains the following software.

    - LoRaWAN(R) Stack and Sample Application
      + LoRaWAN Protocol Stack
        + source code, documents
      + LoRaSample (LoRaWAN sample application with AT-command)
        + source code, binary, documents
      + LoRaFuotaSample (Firmware Update over LoRaWAN sample application with AT-command)
        + source code, binary, documents

    - Private LoRa Stack and Sample Application
      + Private LoRa Stack
        + source code, documents
      + Private LoRa Sample Application with AT-command
        + source code, binary, documents
      + LoRaWAN(R) and Private LoRa Combination Sample Application with AT-command
        + source code, binary, documents

    - LoRa(R) Radio Driver, Sample Applications
      + Radio Driver for LoRa
        + source code, API specification
      + RadioEvalApp (Radio Evaluation Program with AT-command)
        + source code, binary, documents
      + ping-pong (Simple Sample Application using Radio Driver)
        + source code, no binary, no documents

    - Evaluation Tools
      + Renesas LPWA Studio (Windows GUI front end for RadioEvalApp)
        + executable binary, documents, script for Wireshark
      + Renesas LPWA Power Estimator (Windows Excel Application Program)
        + excel work sheet, documents

  For more detail, please refer to each release note for the software located in
  (package top)\documents\(software)\RELEASENOTE.TXT
