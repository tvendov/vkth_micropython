class DAC -- digital to analog conversion
=========================================

The DAC is used to output an analog voltage based on a digital value.

The output voltage will be between 0 and 3.3V.

DAC is currently supported on ESP32 [#esp32_dac]_, SAMD and Renesas RA.

.. note::
  The STM32 port has similar functionality to ``machine.DAC``. See
  :ref:`pyb.DAC <pyb.DAC>` for details.

Example usage (ESP32)::

    from machine import DAC

    dac = DAC(pin)    # create a DAC object acting on a pin
    dac.write(128)    # write a value to the DAC
    dac.write(255)    # output maximum value, 3.3V

Constructors
------------

.. class:: DAC(id)

  Construct a new DAC object.

  ``id`` is a pin object (ESP32 and Renesas RA) or an index to a DAC resource (SAMD).

.. note::
  On the ESP32, DAC functionality is available on pins 25 and 26. On the
  ESP32-S2, pins 17 and 18. See :ref:`ESP32 Quickref <esp32_quickref>`
  for more details.

.. note::
  SAMD21 has one DAC resource, SAMD51 has two. See :ref:`SAMD Quickref <samd_quickref>`
  for more details.

Methods
-------

.. method:: DAC.write(value)

  Output an analog voltage to the pin connected to the DAC.

  ``value`` is a representation of the desired output; a linear interpolation of
  0-3.3V, though the range differs depending on the port and micro, see below:

  +--------------+------+--------+
  | *Port/micro* | Bits | Range  |
  +==============+======+========+
  | ESP32        | 8    | 0-255  |
  +--------------+------+--------+
  | SAMD21       | 10   | 0-1023 |
  +--------------+------+--------+
  | SAMD51       | 12   | 0-4095 |
  +--------------+------+--------+
  | Renesas RA   | 12   | 0-4095 |
  +--------------+------+--------+

.. method:: DAC.read()

  Return the current raw DAC value.

  This method is currently supported on Renesas RA.

.. method:: DAC.write_mv(value)

  Output an analog voltage using millivolts instead of raw DAC units.

  ``value`` must be in the range ``0`` to ``3300``.

  This method is currently supported on Renesas RA.

.. method:: DAC.read_mv()

  Return the current DAC output value in millivolts.

  This method is currently supported on Renesas RA.

.. method:: DAC.write_timed(data, freq, *, mode=DAC.NORMAL, transfer=DAC.TRANSFER_AUTO, timer=None)

  Start timed playback from a buffer of DAC samples.

  ``data`` must provide a 16-bit aligned read buffer whose entries are 12-bit
  DAC values in the range ``0`` to ``4095``.  Using ``array('H', ...)`` is the
  most portable choice.

  ``freq`` is the DAC sample rate in Hz.

  ``mode`` can be ``DAC.NORMAL`` for one-shot playback or ``DAC.CIRCULAR`` for
  looping playback.

  ``transfer`` selects the transfer engine:

  +----------------------+--------------------------------------------------+
  | ``DAC.TRANSFER_AUTO``| Select the default backend for the current mode. |
  +----------------------+--------------------------------------------------+
  | ``DAC.TRANSFER_DMAC``| Use the DMAC backend.                            |
  +----------------------+--------------------------------------------------+
  | ``DAC.TRANSFER_DTC`` | Use the DTC backend.                             |
  +----------------------+--------------------------------------------------+

  ``timer`` optionally selects the AGT timer channel used as the sample clock.
  If omitted, a free AGT timer is chosen automatically.

  On the current Renesas RA implementation:

  - ``DAC.NORMAL`` supports one-shot playback with ``DMAC`` or ``DTC``.
  - ``DAC.CIRCULAR`` is implemented with ``DTC`` and currently supports up to
    256 samples.
  - ``DAC.TRANSFER_AUTO`` selects ``DMAC`` for ``DAC.NORMAL`` and ``DTC`` for
    ``DAC.CIRCULAR``.

  Example::

      from array import array
      from machine import DAC, Pin

      buf = array("H", [2048, 3072, 4095, 3072, 2048, 1024, 0, 1024])
      dac = DAC(Pin("P014"))
      dac.write_timed(buf, 440 * len(buf), mode=DAC.CIRCULAR)

.. method:: DAC.stop()

  Stop timed playback started by :meth:`DAC.write_timed`.

  This method is currently supported on Renesas RA.

.. method:: DAC.playing()

  Return ``True`` while timed playback is active.

  This method is currently supported on Renesas RA.

Constants
---------

.. data:: DAC.NORMAL

  One-shot timed playback mode.

  This constant is currently supported on Renesas RA.

.. data:: DAC.CIRCULAR

  Looping timed playback mode.

  This constant is currently supported on Renesas RA.

.. data:: DAC.TRANSFER_AUTO
.. data:: DAC.TRANSFER_DMAC
.. data:: DAC.TRANSFER_DTC

  Transfer backend selection constants for :meth:`DAC.write_timed`.

  These constants are currently supported on Renesas RA.

.. rubric:: Footnotes

.. [#esp32_dac] The original ESP32 and ESP32-S2 *only*, since DAC hardware is
    not present on other microcontrollers in the family.
