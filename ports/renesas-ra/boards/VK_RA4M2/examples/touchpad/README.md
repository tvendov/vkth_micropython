## TouchPad / CTSU knowledge

This directory captures the current RA4M2 CTSU knowledge used by the
`machine.TouchPad` port and the planned capacitance-meter extension.

Files:

- `CTSU_HOW_IT_WORKS.md`
  Functional model of CTSU1 on RA4M2, with the current wrapper defaults.
- `CTSU_REGISTERS.md`
  Register-level notes for the bits that matter to range, timing, and raw counts.
- `TOUCHPAD_CAPMETER_V1_CONTRACT.md`
  The agreed `machine.TouchPad` metrology contract for the first patch.
