Аудио и Ретро Синтезатор на VK-RA4M2
======================================

Тази страница описва текущата поддръжка за timed-DAC аудио възпроизвеждане
на ``VK_RA4M2`` и показва как да я използвате за ретро игрови звукови
ефекти и просто музикално възпроизвеждане. Придружаващите примерни файлове
се намират в ``ports/renesas-ra/boards/VK_RA4M2/examples/``.

Общ преглед
-----------

Текущият ``VK_RA4M2`` фърмуер поддържа timed DAC възпроизвеждане чрез
класа ``machine.DAC``. Пътят на семплите е хардуерно управляван:

- ``DAC.write_timed(...)`` настройва възпроизвеждането
- ``AGT`` таймер осигурява тактовия сигнал за семплите
- ``DMAC`` или ``DTC`` прехвърля семпли от RAM към DAC регистъра
- DAC преобразува стойностите в аналогов изход

Подходящо е за:

- чиптюн стил тонове
- малки wavetable цикли
- звукови ефекти за скок / монета / лазер / експлозия
- прости мелодии и арпеджа

Не е предназначено за дълго hi-fi PCM възпроизвеждане.

Пинове
------

На ``VK_RA4M2``:

- ``P014`` е ``DA0`` на ``J19-5`` и Arduino ``A4``
- ``P015`` е ``DA1`` на ``J19-6`` и Arduino ``A5``

.. note::

   ``J16`` е jumper за boot режим. Той **не е** DAC изход.

Основна работа с DAC
---------------------

Използване на DAC като нормален аналогов изход::

    from machine import DAC, Pin

    dac = DAC(Pin("P014"))
    dac.write(2048)      # около средната стойност
    print(dac.read())
    dac.write_mv(1650)   # около половината от 3.3 V
    print(dac.read_mv())

Timed възпроизвеждане
---------------------

Timed възпроизвеждането използва 16-битово подравнен буфер от 12-битови
семпли в обхвата ``0`` до ``4095``. ``array('H', ...)`` е препоръчаният
тип буфер::

    from array import array
    from machine import DAC, Pin
    import time

    wave = array("H", [2048, 3072, 4095, 3072, 2048, 1024, 0, 1024])
    dac = DAC(Pin("P014"))

    dac.write_timed(
        wave,
        440 * len(wave),
        mode=DAC.CIRCULAR,
        transfer=DAC.TRANSFER_DTC,
    )
    time.sleep_ms(500)
    dac.stop()

Режими на възпроизвеждане:

- ``DAC.NORMAL`` — изпълнява буфера еднократно
- ``DAC.CIRCULAR`` — повтаря буфера циклично

Трансферни backend-ове:

- ``DAC.TRANSFER_AUTO`` — избира backend по подразбиране
- ``DAC.TRANSFER_DMAC`` — избира ``DMAC``
- ``DAC.TRANSFER_DTC`` — избира ``DTC``

При текущата ``VK_RA4M2`` имплементация:

- ``DAC.NORMAL`` поддържа ``DMAC`` и ``DTC``
- ``DAC.CIRCULAR`` използва ``DTC``
- цикличният режим поддържа до ``256`` семпъла
- ``timer=<n>`` може да се използва за избор на конкретен ``AGT`` канал

Защо 256 семпъла са достатъчно
--------------------------------

При ретро аудио буферът обикновено е един период на вълната, не дълъг
записан семпъл. Честотата на тона идва от скоростта на възпроизвеждане:

``sample_rate = честота_на_нотата * дължина_на_таблицата``

Примери с таблица от ``256`` семпъла:

- ``220 Hz`` -> ``56320 Hz``
- ``440 Hz`` -> ``112640 Hz``
- ``880 Hz`` -> ``225280 Hz``

Достатъчно е за:

- квадратни и пулсови вълни
- триъгълни и трионовидни вълни
- кратки циклични wavetable-и
- синтетични игрови звукови ефекти

Хардуерно верифициран статус
-----------------------------

Текущият фърмуер на ``VK_RA4M2`` е верифициран на реален хардуер за:

- ``DTC`` циклично възпроизвеждане
- ``DTC`` еднократно възпроизвеждане
- ``DMAC`` еднократно възпроизвеждане

``DMAC`` пътят изискваше TrustZone-свързана корекция, за да може избраният
DMAC канал да използва правилната атрибуция за сигурност преди стартиране
на възпроизвеждането.

Примерни файлове
-----------------

Директорията с примери на ``VK_RA4M2`` включва:

- ``retro_synth.py``: помощен модул за ноти, sweep, арпеджа и SFX
- ``dac_retro_sfx.py``: готово демо за монета / скок / лазер / експлозия
- ``dac_retro_music.py``: готово демо за мелодия плюс арпеджо
- ``dac_firmware_probe.py``: директна валидация на фърмуера за timed DAC
- ``dac_dmac_diag.py``: допълнителна DMAC регистрова диагностика за
  отстраняване на проблеми с еднократния трансфер

RetroSynth помощен модул
-------------------------

Примерите на платката включват помощен модул на име ``retro_synth.py``.
Той осигурява:

- wavetable таблици: ``square``, ``pulse50``, ``pulse25``, ``pulse12``, ``triangle``, ``saw``
- имена на ноти като ``"A4"`` и ``"C#5"``
- възпроизвеждане на ноти
- pitch sweep (плавна промяна на височината)
- възпроизвеждане на арпеджо
- просто възпроизвеждане на мелодия
- готови звукови ефекти
- автоматичен fallback от ``DMAC`` към ``DTC`` за noise-burst помощната функция

Пример::

    from retro_synth import RetroSynth

    synth = RetroSynth("P014")
    synth.play_note("A4", 120, "pulse25")
    synth.play_arpeggio("A3", (0, 4, 7, 12), step_ms=60, cycles=4, wave="triangle")
    synth.coin()

Вградени звукови ефекти:

- ``coin()`` — монета
- ``jump()`` — скок
- ``laser()`` — лазер
- ``explosion()`` — експлозия

Практически съвети
-------------------

- Използвайте ``P014``, освен ако изрично не искате втория DAC канал на ``P015``.
- Използвайте ``array('H', ...)`` за буфери със семпли.
- Дръжте стойностите на семплите в обхвата ``0`` до ``4095``.
- Използвайте ``DTC`` цикличен режим за повтарящи се синтезаторни тонове.
- Използвайте ``DMAC`` еднократен режим за burst ефекти като шум или удар.
- За ретро звуков дизайн мислете в термини на синтез и промени с контролна
  скорост, не дълги аудио клипове.

Предложени следващи стъпки:

- добавете повече wavetable форми
- добавете обвивки (envelopes) и вибрато
- наслоете множество ефекти в Python контролен код
- изградете малък game-audio API върху ``RetroSynth``
