## Key Concepts

### GATT Database
Static configuration of BLE services and characteristics.
Must be set before advertising starts.
**File:** `GATT_DB_TECHNICAL_ANALYSIS.md`

### Three Integration Approaches
1. **Static:** Use Renesas QE tool (1-2 days)
2. **Dynamic:** Implement Python wrapper (1-2 weeks)
3. **Hybrid:** Static base + dynamic extensions (2-3 weeks)
**File:** `GATT_DB_INTEGRATION_GUIDE.md`

### Current Gap
GATT DB is NOT configured in current implementation.
Result: Device has no services to advertise.
**File:** `CURRENT_STATUS_2026-01-10.md`
